# dsh-engram v0.7.12

**把 v0.7.11 的结论做成一行可读的证据**，省得下一个人（或三个月后的我）重走一遍。

## 改了什么

- `npx dsh-engram status` 新增一行：

  ```
  账本两条腿：engram 剪枝 7841 字符 · 宿主自剪 64200 字符（宿主腿远大于 engram 腿 → 先确认边界源有没有覆盖到你的用法）
  ```

  三种判词：宿主全干 / 宿主腿远大于 engram 腿 / 持平。这行**不依赖状态快照**（读的是账本，
  不是插件启动状态），所以没跑过 web 也能看。
- 设置卡 `boundaryPrune` 的提示补一句：打开前先看这行，「宿主腿远超 engram 腿时，打开只是重复劳动」。
- 测试：CLI 集成测试固定这条输出（442/442）。

## 为什么值得单独发一版

v0.7.11 关掉 L1 是个**判断**，判断会过期——宿主换版本、边界源改覆盖率、idle cadence 有了新证据，
结论都可能翻。把判断的依据做成一条随时可读的输出，比写在发布说明里更可靠：发布说明没人重读，
`status` 会被顺手跑。
